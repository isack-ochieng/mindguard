BUILT FOR CONTROL, NOT SURVEILLANCE

Protection that keeps the network path simple.

MindGuard is intentionally narrow in scope. It evaluates domain requests against local policy instead of decrypting web traffic or routing your entire connection through a remote proxy.

01

Local domain decisions

Blocked-domain matching happens on the device. A request can be denied locally without sending the destination to a MindGuard server.

02

Lightweight filtering

The current app focuses on DNS traffic. It does not use TLS interception, tun2socks/HEV tunnelling, or a SOCKS proxy.

03

Simple control

Manage the local not-trusted domain list and view protection status from the MindGuard interface.

04

Optional AI assistance

The optional domain-intelligence feature can classify a predefined candidate list. It is designed not to send browsing history or page contents to Gemini.

HOW IT WORKS

A straightforward three-step flow.

1

Protection starts

Android grants MindGuard a local VPN interface used for DNS-level filtering.

2

The domain is checked

The local decision engine compares DNS requests with your not-trusted policy.

3

Only the decision is applied

Blocked domains receive a local negative response; allowed or unknown requests can continue normally.

Important limitation: DNS filtering is not the same as full web inspection. Direct-IP connections, some DNS-over-HTTPS or Private DNS implementations, cached results, and other network behaviours can bypass a DNS-only policy.

AUTHORIZED USE

Made for responsible digital protection.

MindGuard is intended for authorized parental-control, self-control, productivity, educational, and research use. Do not install or configure network controls on another person's device without appropriate authorization.
